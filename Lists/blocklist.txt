# ============================================================================
# 自定义拦截名单 —— 手动维护

#
# 用途：拦截上游规则没有覆盖的域名（例如你自己遇到的漏网广告域）。
#       本文件参与全部三个版本（Full / Lite / Slim）的构建。
#
# 格式（两种写法都支持，任选其一）：
#     1. 裸域名          example.com
#     2. AdGuard 语法    ||example.com^
#
# 规则说明：
#     - 以 ! 或 # 开头的行视为注释，空行忽略
#     - 大小写不敏感，会自动转为小写
#     - 写主域即可拦截其全部子域（AdGuard Home 中 ||example.com^ 已含子域）
#     - 与 Lists/whitelist.txt 冲突时以白名单为准：
#       同一域名同时出现在两个文件里，本文件的该条目会被忽略并打印警告
#
# 生效方式：提交本文件后，GitHub Actions 会在下次运行时自动纳入。
# ============================================================================
